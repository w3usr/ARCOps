Computer Use Agreement

The club's shared computer account exists so that members can use the common station log and the station's licensed radio software. Members who receive the account password agree to the following conditions.

  1. I will use the account and the station computers only for amateur radio and related club purposes.
  2. I will not share the password with others or write it down.
  3. I will not install software without the advisor's permission.
  4. I will protect the integrity of the station log, shared data, and software configuration.
  5. I will follow the computing policies of the institution that hosts the station.
  6. I will report any problem with the computers to the advisor without delay.

Term

This agreement is in force from its approval until the expiry date the approver sets. The account password is rotated periodically; members with a current agreement see the current password in the application and nowhere else.
